# 纸墨 Paper Ink · EdgeEver 主题

暖纸亮色 + 墨绿暗色的 EdgeEver 阅读主题。

## 安装

在 EdgeEver 插件市场填写仓库地址安装：

```text
https://github.com/ZhenYu-Jiang/edgeever-paper-ink-theme
```

启用后即可生效。同一时间只能启用一个主题，启用新主题会自动停用旧主题。

## 配色

- 亮色：暖纸底色 `#f6f2e9`、暖白卡片、绿强调 `#356b50`，辅助文字加深为 `#6b6356`。
- 暗色：墨绿深底 `#1c201e`、柔和绿强调 `#6fbe94`。
- 字体：正文系统无衬线，代码走等宽字体（ui-monospace / JetBrains Mono）。
- 主题字号 `16px`、正文行距 `1.75`、正文宽度上限 `800px`，界面密度保持 `1`。

## 1.1.0

改善浅色辅助文字和链接的可读性，并明确正文与代码使用不同字体。浅色辅助文字在主题三种背景上的最低对比度从 3.68:1 提升为 4.85:1；正文、辅助文字、强调文字和按钮文字的所检查配色组合均至少 4.5:1。数值按主题纯色配置计算。

可直接打开仓库中的 `preview.html` 查看明暗阅读样例，不需要联网。预览用于检查配色和排版，不是实际 EdgeEver 工作区截图；宿主的组件样式和内容宽度约束仍会影响最终显示。

## 发布

安装资产只有 `manifest.json`，无需 main.js / styles.css。源码仓库另带独立预览与发布流程。发布与版本号一致的标签（如 `1.1.0`），GitHub Actions 检查 JSON 后创建仅包含 manifest 的 Release。
